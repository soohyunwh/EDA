# White Wine Quality Analysis

이 프로젝트는 화이트 와인 품질 데이터를 활용한 기초 데이터 분석(EDA) 및 이상치 탐지를 목적으로 합니다.

## 주요 내용

- pandas를 이용한 데이터 로딩 및 전처리
- describe()를 활용한 기초 통계 확인
- boxplot을 통한 이상치 시각화 (예: density)
- IQR 기반 이상치 탐지 코드 작성
- Plotly로 interactive 시각화 시도

## 사용 기술
- Python (pandas, matplotlib, seaborn, plotly)
- Jupyter Notebook
